# 🔮 NLP Next-Word Predictor

An interactive language modeling project that predicts the next word(s) based on user input using a **Bigram Model**.

✨ Includes:
- ✅ Next-word auto-completion
- 📈 Probability visualizations with Matplotlib
- 📂 Custom file upload for training the model

---

## 🚀 How It Works

1. Tokenizes and trains a Bigram language model using NLTK
2. Predicts top 5 possible next words based on user input
3. Shows a probability bar chart to explain prediction strength
